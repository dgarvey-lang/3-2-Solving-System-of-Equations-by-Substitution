Notes: Solving a System by Substitution

Read these steps. You'll use them for every example below.

  1. Solve one equation for the easiest variable to isolate (get it alone).
  2. Substitute the expression from step 1 into the other equation for that variable.
  3. Solve for the remaining variable.
  4. Substitute the value from step 3 into either equation to find the other variable.
  5. Check the point in both original equations.
